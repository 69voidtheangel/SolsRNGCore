# Code of Conduct

## Our Standards

SolsRNGCore is an open-source project built for the Sol's RNG community. We want this project to be a place where people can learn, contribute, report problems, and share ideas without being harassed or treated disrespectfully.

Examples of behavior that contribute to a positive environment include:

- Being respectful and constructive.
- Welcoming people with different levels of technical experience.
- Giving useful feedback without attacking the person who made something.
- Being open to different approaches and opinions.
- Respecting project maintainers, contributors, and users.
- Reporting bugs and security issues responsibly.
- Giving credit when using someone else's work.
- Assuming good intent while still addressing problems when they occur.

## Unacceptable Behavior

The following behavior is not acceptable:

- Harassment, bullying, threats, or intimidation.
- Discrimination or hateful behavior toward any person or group.
- Personal attacks, insults, or deliberately hostile behavior.
- Sexual harassment or inappropriate sexual behavior.
- Publishing someone's private or personal information without permission.
- Deliberately disrupting discussions, issues, pull requests, or other project spaces.
- Spam, excessive self-promotion, or intentionally misleading contributions.
- Malicious code, intentionally harmful changes, or attempts to compromise users or contributors.
- Impersonating project maintainers or other contributors.
- Attempting to evade moderation actions or repeatedly returning to cause disruption.

## Project-Specific Expectations

SolsRNGCore interacts with games, automation tools, Discord services, and user-configured systems.

Contributors are expected to:

- Avoid intentionally adding features designed to steal credentials, tokens, cookies, or other private information.
- Never commit personal configuration files, authentication credentials, Discord webhook URLs, role IDs, private server information, or other secrets.
- Avoid submitting code that intentionally damages a user's system or data.
- Clearly disclose potentially disruptive or experimental changes.
- Respect the rules and policies of services that SolsRNGCore interacts with.
- Keep user privacy and security in mind when designing new features.

## Reporting Problems

If you experience or witness behavior that violates this Code of Conduct, please report it to the project maintainers through the project's GitHub repository.

When reporting an issue, provide as much relevant information as you can without sharing private or sensitive information.

Reports will be reviewed by the project maintainers and handled as appropriate.

## Enforcement

Project maintainers may take any action they consider appropriate in response to behavior that violates this Code of Conduct, including:

- Asking someone to stop inappropriate behavior.
- Removing comments, issues, pull requests, or other content.
- Temporarily restricting participation.
- Permanently restricting participation.
- Removing contributions that violate project standards.

Enforcement decisions will be made based on the circumstances of the situation.

## Scope

This Code of Conduct applies to project spaces, including:

- GitHub issues
- Pull requests
- Discussions
- Code reviews
- Project-related communication spaces
- Other spaces where someone is representing or acting on behalf of SolsRNGCore

## Attribution

This Code of Conduct is inspired by the principles of the Contributor Covenant and has been adapted for SolsRNGCore.

By participating in SolsRNGCore, you agree to help maintain a respectful, constructive, and welcoming community.
